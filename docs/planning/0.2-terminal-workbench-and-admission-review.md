# 0.2 terminal workbench and admission review

## Outcome and budget

This fourth implementation batch adds a useful experimental read-only terminal
view and closes the composition seam for inert all-pass runtime review material.
Both support the [product delivery checkpoints](../roadmap.md#product-delivery-checkpoints).
Neither completes a qualified local rewrite or the full 1.0 workbench.

External spending remains $0. Work uses existing local tooling and synthetic
fixtures. The [current-state document](../current-state.md) remains the authority
for implemented behavior; local integration results are recorded below.

## Implemented slices

| Component | Implementation and boundary |

| Inert all-pass admission review | [Compiler](../../crates/app/src/runtime_admission_evidence/review.rs), [exact input joins](../../crates/app/src/runtime_admission_evidence/review/input.rs), and [retained source revalidation](../../crates/app/src/runtime_admission_evidence/review/source.rs) derive canonical schema-2 review material from existing opaque passed controls and cleanup-gated execution records, with independent structural verification |
| Real bootstrap defect | [Rust component installer](../../crates/runtime-isolation/src/platform/linux_bootstrap_root_native/toolchain.rs) validates exact manifest-declared payloads before merging them and retains installer metadata in its source components; the three pinned official component archives no longer collide at `manifest.in` |

`retonr tui SOURCE --candidate FILE --protect TERM` uses the existing application
candidate-check and editorial lint services. Source-only inspection is also
available. Inputs are single regular UTF-8 files up to 16 MiB each. Interactive
mode requires terminal stdin and stdout and refuses JSON. `--plain` supports
redirected text or JSON. Previews are bounded and sanitized; validation uses
complete input. Metadata requiring an explicit derivative decision is refused.

Editorial lint is noncooperative: cancellation discards its result when the call
finishes. Terminal state is restored before waiting for worker cleanup. The
terminal view supplies no profile, folder-navigation, document-write, or model
generation capability.

The admission compiler revalidates exact source and static control relationships,
checks the completed execution authorities, and independently reconstructs the
canonical review. Its output remains inert. It supplies no production approval
policy, admitted-runtime capability, model qualification, or generation authority.
Synthetic review fixtures cannot establish those real-runtime facts.

### Terminal cleanup and coverage follow-up

Rendering now shares a synchronization gate with panic restoration. A background
abort waits for the active frame and prevents later frames from hiding the restored
cursor. Owner-thread restoration avoids relocking during a panic. The focused
terminal suite passes 34 tests, including active-frame cursor ordering, owner
deadlock prevention, and poisoned-lock cleanup. Strict CLI lint and the default
Windows shipping build pass; combined local line coverage is 81.22 percent.

The first remote coverage job completed its tests and native gates but failed to
merge a structurally corrupt ordinary raw profile. The workflow now validates
root-level profiles with the exact Rust LLVM tool, retains malformed bytes and
diagnostics, requires valid ordinary and native profiles, and still enforces the
80 percent floor. Tool failures, unsupported versions, and unexpected diagnostics
remain fatal. Actual instrumented-profile fixtures cover valid, truncated, empty,
all-invalid, indirect, and destination-collision cases. Every valid profile is kept.

### Bootstrap archive follow-up

The actual vendor tree contains 19,781 files. Retaining descriptors for every file
and a second complete snapshot exceeded the frozen 4,096 descriptor ceiling.
Bootstrap stage two now provides a private capability only after its existing root,
privilege, read-only mount, and filesystem isolation checks. The helper uses three
retained root descriptors, bounded numeric snapshots, anchored per-file reads,
complete archive readback, and the existing exact input comparison. Public mutable
normalization and all four rebuilt-program comparisons remain unchanged.

The mandatory native fixture successfully serializes 8,193 files under the actual
4,096 descriptor limit and rejects changed content, links, FIFO inputs, and nested
mounts. Separate native fixtures match long paths and executable source modes to
the public normalizer and compare the actual retained source, vendor, and raw crate
archives. Corrupt output and same-byte output identity replacement regressions
also pass. The instrumented isolation library passes 138 tests; combined local
line coverage remains 80.95 percent. CI runs the synthetic native fixture and
includes its profile in coverage.

A fresh committed source freeze and rebuilt retained programs remain necessary
before independently authenticated bootstrap and runtime build attempts. Prepared
archives, matching hashes, and passing fixtures do not supply production authority.
