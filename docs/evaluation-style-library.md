# Writing-sample and style-impression library

## Purpose

This library gives development tests three kinds of text that must stay separate:

1. Licensed pre-model human prose used as a control
2. Synthetic impressions of public assistant styles
3. Research cases that refuse to treat style or folklore as a watermark

None of these files is an authorship detector, a vendor fingerprint, or a
known-watermark suite. Editorial lint may later use the synthetic impression
rules. Watermark science still requires a pinned public embedder.

## What is checked in

| File | Role |
| --- | --- |
| `crates/eval/fixtures/editorial_model_impressions_v1.json` | 8 paired lint rules for common assistant residue |
| `crates/eval/fixtures/editorial_assistant_residue_v1.json` | 10 paired lint rules for later assistant residue |
| `crates/eval/fixtures/writing_samples/licensed_pre_ai_human_v1.json` | Four pre-2000 RFCs, USGS 1996, NIST SP 800-12 (1995), CDC MMWR 1999, and a 2003 PLOS Biology paper |
| `crates/eval/fixtures/writing_samples/synthetic_model_impressions_v1.json` | Maintainer-written ChatGPT, Claude, Grok, and Gemini impressions |
| `crates/eval/fixtures/watermark_research/style_is_not_a_watermark_v1.json` | Style-as-mark refusals, unmarked controls, Unicode and comment observations |

The synthetic impressions were written in-tree. No remote model API was called.
That keeps the data-policy local-only rule, stays at $0 spend, and avoids unmarked
provider output that we could not honestly treat as a vendor sample.

## Licensed human controls

The IETF Trust Legal Provisions permit reproduction of RFCs. Each excerpt records
title, canonical URL, year, and notice. The USGS essay, NIST handbook, and CDC
methods report are U.S. government works (17 U.S.C. 105) recorded under the
CC-PDDC SPDX token. The PLOS Biology paper is open access under the 2003 PLOS
Open-Access License, recorded as CC-BY-4.0. Seven works were published before
2000. The PLOS paper is 2003, still years before neural language models were
common.

These excerpts are controls for cadence across specification, handbook, methods,
popular-science, and journal registers. They do not prove that a later document
is human-written.

Nineteenth-century scientific books were reviewed and left out. Several official
plain-text editions contain U+2013 or U+2014, which this repository does not
admit, and altering those marks would no longer be an exact excerpt. Journal PDFs,
default arXiv licenses, and NC-only texts stay out. Public-domain or CC-BY papers
may be added later only with a recorded license decision and characters the
repository can store unchanged.

## Model-family impressions

The impressions capture editorial habits people associate with assistants:

- ChatGPT-like: `Certainly!`, scene setting, transition pileup, empty close
- Claude-like: sycophantic affirmation, careful hedge, both-sides symmetry, follow-ups
- Grok-like: casual direct address and certainty theater in a finished memo
- Gemini-like: helper opener, found-list packaging, bold labeled bullets, hope-this-helps close

Each family has a short memo and a longer article except Gemini, which is article
length. Each habit is an explainable editorial defect in a finished document. A
clean neighbor exists for every new rule. A match is not a vendor identification.

## Watermark research fence

Known-watermark fixtures must be generated by a named public scheme. This
repository does not invent marked text from style. The research corpus only
admits `refused_style_as_mark`, `literal_observation`, `carrier_shape_unparsed`,
and `unmarked_control`. It forbids `watermark_free` and `watermarked` labels.

## Commands

```console
cargo run --locked -p rewrite-eval -- --editorial-corpus crates/eval/fixtures/editorial_model_impressions_v1.json
cargo run --locked -p rewrite-eval -- --editorial-corpus crates/eval/fixtures/editorial_assistant_residue_v1.json
cargo run --locked -p rewrite-eval -- --writing-samples crates/eval/fixtures/writing_samples/licensed_pre_ai_human_v1.json
cargo run --locked -p rewrite-eval -- --writing-samples crates/eval/fixtures/writing_samples/synthetic_model_impressions_v1.json
cargo run --locked -p rewrite-eval -- --watermark-research crates/eval/fixtures/watermark_research/style_is_not_a_watermark_v1.json
```
