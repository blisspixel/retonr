# Milestone 0.1 refinement record

## Status

Status: in progress. This record does not close milestone 0.1. Owner approval of
governance documents, remaining adversarial backend fixtures, final closure-revision
continuous integration, and final review disposition are still open.

Scope reviewed: deterministic contracts, plain-text adapter, common engine,
candidate-check service and CLI, evaluation and baseline harness, model and inference
contracts, native Ollama adapter, and grounded application path.

## Pass 1: correctness and boundaries

Completed checks:

- Separated immutable artifact facts, qualification evidence, activation decisions,
  and active bindings.
- Added a backend-neutral object-safe inference port and deterministic fake.
- Separated observed source bytes, qualified source capacity, and complete serialized
  prompt capacity.
- Kept grounded generation outside acceptance and document application.
- Routed grounded candidates through the common protection, structure, safety,
  semantic, and ranking path.
- Preserved the exact original on deterministic abstention and cancellation.

Findings corrected:

- The first baseline and Ollama modules exceeded the source-file size policy. Tests
  and response, contract, and transport responsibilities were split into cohesive
  modules.
- IPv6 loopback parsing initially rejected the bracketed URL form and was corrected.
- Ollama digests were normalized from the documented `sha256:` wire representation
  to the canonical internal digest type.
- Prompt input length had been conflated with source length and was separated before
  broader use.

Open disposition:

- Durable generation provenance is not yet linked into the versioned transaction
  record.
- The current semantic evaluator is intentionally literal-only. Broader modes remain
  uncertain.

## Pass 2: adversarial and cross-platform

  and response bounds have deterministic tests.
- Redirect, disconnect, truncated body, oversized body, wrong content type,
  preflight deadline, in-flight body deadline, exact generation parameters, and
  post-generation digest drift have deterministic loopback transport tests.
- Workspace properties, process tests, and repository policy checks pass locally on
  Windows.
