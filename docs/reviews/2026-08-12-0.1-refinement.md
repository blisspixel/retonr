governance documents, final closure-revision continuous integration, and final review

## Pass 1: correctness and boundaries

Completed checks:

- Separated immutable artifact facts, qualification evidence, activation decisions,
  and active bindings.
- Added a backend-neutral object-safe inference port and deterministic fake.
- Separated observed source bytes, qualified source capacity, and complete serialized
  prompt capacity.
- Kept grounded generation outside acceptance and document application.
- Routed grounded candidates through the common protection, structure, safety,
  semantic, and ranking path.
- Preserved the exact original on deterministic abstention and cancellation.

Findings corrected:

- The first baseline and Ollama modules exceeded the source-file size policy. Tests
  and response, contract, and transport responsibilities were split into cohesive
  modules.
- IPv6 loopback parsing initially rejected the bracketed URL form and was corrected.
- Ollama digests were normalized from the documented `sha256:` wire representation
  to the canonical internal digest type.
- Prompt input length had been conflated with source length and was separated before
  broader use.

Open disposition:

  record.
- The current semantic evaluator is intentionally literal-only. Broader modes remain
  uncertain.

## Pass 2: adversarial and cross-platform

Completed checks:

- Endpoint parsing rejects hostnames, non-loopback addresses, TLS URLs, credentials,
  query strings, fragments, and non-root paths.
- The HTTP client is configured with reqwest 0.13.4 `no_proxy()`, redirect following
  disabled, automatic retries disabled, referrers disabled, and HTTP/1 only.
- Discovery, generation, digest drift, cancellation, structured candidate parsing,
  and response bounds have deterministic tests.
- Redirect, disconnect, truncated body, oversized body, wrong content type,
  preflight deadline, in-flight body deadline, exact generation parameters, and
  post-generation digest drift have deterministic loopback transport tests.
- A process-isolated proxy-canary test independently exercises the upper- and
  lower-case HTTP and all-proxy variables. A default reqwest client must reach the
  armed canary, while the Ollama adapter must contact only its configured loopback
  fake backend. The child environment removes both proxy-exclusion variables and
  inherited CGI state.
- The quality workflow includes an Ubuntu job that compiles the Ollama adapter tests
  before entering an OS network namespace, brings up loopback as its only interface,
  confirms both main route tables are empty, confirms a non-loopback connection
  fails, and then executes the compiled test binaries.
- Concurrency fixtures exercise cloned adapter handles and prove that operations are
  admitted up to the configured limit, excess work remains queued, queued
  cancellation and deadlines perform no HTTP work, and a permit is recovered after
  an in-flight transport failure.
- Workspace properties, process tests, and repository policy checks pass locally on
  Windows.
